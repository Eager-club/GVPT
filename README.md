# 🌐 College Website

A responsive, user-friendly, and informative website designed for GVPT, built to represent the departments, campus life, and essential resources for students, faculty, and visitors.

## 🚀 Features

- 🏫 Homepage with banner, quick links, and announcements
- 🧭 Departments section with vertical navbar and dynamic content
- 🎓 Academic programs overview
- 🗓️ Events and news highlights
- 🖼️ Gallery with 360° campus tour
- 📞 Contact form with location map
- 🌓 Dark and light mode support
- 📱 Fully responsive for mobile, tablet, and desktop

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, React.js
- **Styling:** Tailwind CSS / Custom CSS
- **Font:** Nothing Sans (custom font)
- **Icons:** Font Awesome / Lucide
- **Images:** Optimized JPEG/PNG with fallback
- **Hosting:** GitHub Pages / Netlify / Vercel

## 🧠 Key Highlights

- JavaScript objects are used to manage department and content data for easy maintenance.
- Mobile menu transforms vertical navbar into a smooth animated drawer.
- All departments use dynamic rendering from a central JSON structure.
- 360° image support for virtual campus tour.
- Custom scripts handle toggling views, themes, and interactivity.
